# Zenith-Ops

> *"La diferencia entre un proyecto que existe y uno que no existe es un repositorio con un README."*

**Zenith-Ops** es un proyecto integral de ingeniería y portfolio diseñado para documentar y ejecutar
el camino desde el desarrollo Backend hasta el MLOps y la Ingeniería de Infraestructura de alto nivel.

## Stack Tecnológico

| Capa | Tecnología |
|------|------------|
| Lenguaje | Python 3.12+ con `uv` |
| Backend | FastAPI (Async-first), Pydantic v2 |
| Base de Datos | PostgreSQL + SQLAlchemy 2.0 (Async) + Alembic |
| Testing | Pytest, Ruff, Mypy (strict) |
| ML & Data | Scikit-learn, MLflow, Evidently AI |
| Infraestructura | Docker, Kubernetes, Terraform |
| Observabilidad | Prometheus, Grafana, Loki |
| CI/CD | GitHub Actions |
