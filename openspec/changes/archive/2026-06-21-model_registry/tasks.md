## T-002: ModelRegistryService

**File:** `src/zenith_ops/core/model_registry.py` (same file, append)

Create `ModelRegistryService`:

- `models_dir: Path = Path("models")`
- `_catalog: dict[str, dict[str, ModelMetadata]] | None = None`
- `scan()` — walks `models/`, parses `meta.json`, builds `_catalog`. Skips corrupt entries with warning log.
- `list_models()` → `list[ModelSummary]`
- `get_model(model_id: str)` → `ModelMetadata` (raises `ModelNotFoundError` if unknown)
- `resolve_path(model_id: str)` → `Path` (returns `models_dir / model_id / version / model.joblib`)
- Uses `singleton` pattern (class-level instance or module-level `_registry`)

**Key behavior:** version dirs sorted by semver descending, so first entry = latest.

**Test:** unit tests with temp `models/` directory via `tmp_path` fixture.

**Dependencies:** T-001

## T-006: Update InferenceService to resolve paths via registry

**File:** `src/zenith_ops/core/inference_service.py`

Modify `_load_model`:

```python
@classmethod
def _load_model(cls, model_id: str) -> Any:
    registry = ModelRegistryService.get_instance()
    model_path = registry.resolve_path(model_id)
    try:
        return joblib.load(model_path)
    except FileNotFoundError:
        raise ModelNotFoundError(model_id) from None
```

Remove the old `joblib.load(f"models/{model_id}.joblib")` — no longer needed.

**Dependencies:** T-002
